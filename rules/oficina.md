# Oficina

Solo los roles que la tarea necesite, un agente por rol. El hook `skill-router` puede sugerir uno. Una skill *manual* (`refine`, `decompose`, `delivery`: escriben en Jira) se propone a la persona, nunca se ejecuta sola.

| Rol | Agente | Skills |
| --- | --- | --- |
| PM / PO | sesión + `mecanico` | — |
| Tech Lead | `planificador` (Opus) | `refine`, `delivery`, `plan` |
| Dev | `implementador` | `implement` |
| QA | `revisor-pr` | `audit`, `qa` |
| UX | `visual` | `civitatis-ds` |
